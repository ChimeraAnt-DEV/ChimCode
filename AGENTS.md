# AGENTS.md

Repository-specific knowledge for ChimCode.

## What this is
A full-stack coding tutor. FastAPI backend + dependency-free vanilla JS/Canvas
frontend. Single process serves both the API (`/api/*`) and the SPA.

## Run it
```bash
./run.sh                       # creates venv, installs deps, serves on :12000
# or
cd server && uvicorn app.main:app --host 0.0.0.0 --port 12000
```
Env knobs: `CHIMCODE_SECRET_KEY`, `CHIMCODE_DATA_DIR`, `CHIMCODE_SUPERDAY_COST`,
`CHIMCODE_JWT_HOURS`, `HOST`, `PORT`.

## Key facts
- **No build step** for the frontend. Edit `frontend/*.js` / `styles.css` directly.
- **Standard library only** beyond `fastapi`/`uvicorn`/`pydantic`. Password
  hashing, JWTs, the SQLite layer and icon generation are all stdlib. Keep it
  that way unless there is a strong reason.
- The lesson **engine never executes user code**. It is static analysis only
  (`engine.analyze`). Do not add code execution without a sandbox.
- **707 achievements** are generated deterministically in
  `server/app/achievements.py`. Metrics are resolved in `main.metric_value`.
  If you change lesson counts or add languages, re-check the total stays > 700.
- App icons are generated by `frontend/assets/icon/make_icons.py` (stdlib PNG
  writer). Re-run it after changing the mark.
- The data dir (`server/data/`) is gitignored. `rm -rf server/data` resets it.

## Layout
- `server/app/main.py` — every API route
- `server/app/engine.py` — grading, mistake detection, ghost text, walkthroughs
- `server/app/curriculum/` — one module per language group + `registry.py`
- `server/app/shop.py` — cosmetics catalogue
- `frontend/bot.js` — the Mochi robot (canvas) + speech voice
- `frontend/editor.js` — editor, error markers, ghost text, bot bubble
- `frontend/app.js` — routing, all views, onboarding

## Conventions
- Lessons: add to the relevant `*_lessons.py`, then they appear via the registry.
  Each `Lesson` needs `checks` (list of `contains`/`regex`/etc. from
  `curriculum/schema.py`).
- Keep API responses camelCase for frontend fields, snake_case internally.
- Test with the full flow: register -> onboarding -> submit -> shop -> superday.

## Gotcha
A short-lived background server may still hold port 12000 between runs. Kill it
with a targeted `pkill -f "uvicorn app.main"` style match before restarting.
